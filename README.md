# EXIT — Stock

موقع مخزن وطلبات، والداتابيز بتاعته Google Sheet. نفس فكرة Salary Site:

- الواجهة: `index.html` على **GitHub Pages**
- الباك إند: `Code.gs` (Apps Script Web App) جوه الشيت
- الدخول: يوزر وباسورد من تاب **My user**

## التابات اللي في الشيت

| التاب | فيه إيه |
|---|---|
| **My user** | `Username` · `Password` · `Name` · `Role` (`admin` / `staff`) · `Active` (`Yes` / `No`) |
| **Products** | المنتجات: الكود، السعر، التكلفة، **المخزون**، الحد الأدنى |
| **Orders** | كل طلب: العميل، الأصناف، الإجمالي، الحالة |
| **Movements** | سجل كل حركة: وارد، منصرف، جرد، بيع، مرتجع. فيه مين عملها وإمتى، والرصيد قبل وبعد |

**الصلاحيات:**
- **admin**: كل حاجة. يضيف ويعدّل ويحذف منتجات، ويشوف التكلفة، ويلغي الطلبات.
- **staff**: يعمل طلبات، ووارد ومنصرف وجرد. **مش بيشوف التكلفة** ومش بيعدّل المنتجات.

## الإعداد

1. اعمل Google Sheet جديد ← **Extensions ← Apps Script**.
2. الصق `Code.gs` واعمل **Save**.
3. اختار الفانكشن **`setup`** واضغط **Run** ووافق على الصلاحيات. التابات هتتعمل، ومعاها يوزر `admin` باسورده `change-me`.
4. **غيّر الباسورد** من تاب My user، وضيف باقي اليوزرز.
5. **Deploy ← New deployment ← Web app**:
   - Execute as: **Me**
   - Who has access: **Anyone**
   - انسخ رابط الـ `/exec`.
6. افتح `index.html` وحط الرابط في `const API_URL = "..."`. لو سبته فاضي، صفحة الدخول هتطلبه أول مرة بس.
7. ارفع الريبو على GitHub ← **Settings ← Pages ← Deploy from branch: main / root**.

> لو عدّلت `Code.gs` بعد كده لازم تعمل **Deploy ← Manage deployments ← Edit ← New version**. لو معملتش كده، الموقع هيفضل شغال على النسخة القديمة.

## إزاي شغال

- **طلب جديد**: بيتأكد إن المخزون يكفي الأول، وبعدين يخصم ويسجل حركة `SALE`. ده بيحصل جوه Lock، فلو اتنين عملوا طلب في نفس اللحظة مش هيتباع أكتر من المتاح.
- **إلغاء طلب** (admin بس): بيرجّع الكميات ويسجل حركة `RETURN`.
- **وارد / منصرف / جرد**: الجرد بيخلي المخزون = الكمية الفعلية اللي كتبتها، والفرق بيتسجل.
- **حذف منتج**: بيخفيه بس (`Active = No`)، والحركة القديمة بتفضل زي ما هي.
- **التحديث التلقائي**: الموقع بيحدّث كل دقيقة، فهتشوف طلبات باقي اليوزرز.
- **الأمان**: 5 محاولات دخول غلط بتقفل اليوزر ربع ساعة، والجلسة بتنتهي بعد 6 ساعات من غير استخدام.
- **Demo**: زرار "جرّب Demo" في صفحة الدخول بيشغّل الموقع ببيانات تجريبية، ومفيش حاجة بتتحفظ.

## ملاحظات

- الباسوردات متخزنة نص عادي في الشيت، **فمتشيرش الشيت** مع حد مش أدمن.
