# EXIT — Stock & Sales System

سيستم المخزن والمبيعات بتاع EXIT. الواجهة على GitHub Pages، والباك إند Google Sheet.

## الملفات
| الملف | مكانه |
|---|---|
| `index.html` و `hero.jpg` والأيقونات | ريبو GitHub (Pages) |
| `Code.gs` | Apps Script جوه الشيت. بعد أي تحديث: **Deploy ← Manage deployments ← Edit ← New version** |

## الأكواد
- كل منتج جديد بياخد كود تلقائي: `EX00001`، `EX00002`، وهكذا.
- الاستيكر بيتطبع QR وتحته كود المنتج.
- أي سكان بيفتح بوب أب فيه: الكمية، وسعر بيع الحتة (تقدر تعدّله)، وكود الخصم.
- لو عايز الأكواد تبدأ بحروف غير `EX`، غيّرها من `SKU_PREFIX` في `Code.gs`.

## أكواد الخصم
- **نسبة %** من إجمالي السطر، أو **مبلغ ثابت على الحتة**.
- تقدر تحدد أقصى عدد استخدامات وتاريخ انتهاء، وتوقف الكود أو تشغّله في أي وقت.
