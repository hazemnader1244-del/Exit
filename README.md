# EXIT — Stock & Sales System

سيستم المخزن والمبيعات بتاع EXIT. الواجهة على GitHub Pages، والباك إند Google Sheet.

## الملفات
| الملف | مكانه |
|---|---|
| `index.html` و `hero.jpg` والأيقونات | ريبو GitHub (Pages) |
| `Code.gs` | Apps Script جوه الشيت. بعد أي تحديث: **Deploy ← Manage deployments ← Edit ← New version** |

## التابات اللي بتتعمل لوحدها
Products · Orders · Payments · Discounts · Movements

## الأكواد
- كل منتج جديد بياخد كود تلقائي: `EX00001`، `EX00002`، وهكذا.
- الاستيكر بيتطبع QR وتحته كود المنتج.
- أي سكان بيفتح بوب أب فيه: الكمية، وسعر بيع الحتة (تقدر تعدّله)، وكود الخصم.
- لو عايز الأكواد تبدأ بحروف غير `EX`، غيّرها من `SKU_PREFIX` في `Code.gs`.

## أكواد الخصم
- **نسبة %** من إجمالي السطر، أو **مبلغ ثابت على الحتة**.
- تقدر تحدد أقصى عدد استخدامات وتاريخ انتهاء، وتوقف الكود أو تشغّله في أي وقت.

## الأرشيف (علشان السيستم ميتقلش)
- الطلبات **المقفولة** (المدفوعة بالكامل والملغية) اللي أقدم من 90 يوم بتتنقل لتابات: `Orders Archive` و `Payments Archive` و `Movements Archive`.
- **الموقع مش بيحمّل الأرشيف**، فبيفضل سريع مهما الداتا كبرت.
- **الداشبورد بيفضل شامل كل التاريخ**، لأن مع كل أرشفة بيتحفظ ملخص لكل يوم في تاب `Daily Summary`.
- **الطلبات اللي عليها آجل** مش بتتأرشف لحد ما تتحصّل.
- **أرقام الطلبات** بتكمل بعد الأرشفة من غير ما تتكرر.

**إزاي تشغّله:**
- **من الموقع:** صفحة **الأرشيف** (للأدمن بس). فيها زرار "أرشف دلوقتي" تختار معاه المدة، وبحث في الأرشيف وقت ما تحتاجه.
- **من الشيت:** منيو **📦 EXIT ← شغّل الأرشفة التلقائية**. بعدها هيأرشف لوحده أول كل شهر الساعة 3 الفجر.
